# 🏎️ PITWALL — GP de São Paulo

Projeto de estudo desenvolvido em **HTML e CSS**, inspirado no Grande Prêmio de São Paulo de Fórmula 1.

## Sobre o projeto

O site apresenta informações sobre o GP, incluindo:
- Grid de pilotos
- Classificação dos pilotos
- Filtros por nome e equipe
- Formulário para reserva de ingressos
- Informações do circuito de Interlagos

## Tecnologias

- HTML5
- CSS3
- Google Fonts

## Objetivo

Praticar a criação de páginas web, formulários, tabelas, navegação por seções e estilização com CSS.
